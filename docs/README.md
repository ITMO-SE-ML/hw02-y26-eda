# Документация к ДЗ 2

Здесь собраны инструкции по работе с репозиторием и справка по инструментам. Требования к результату находятся в [условии задания](../README.md).

## С чего начать

1. [Запустите приложение](starter.md#первый-запуск) - установите библиотеки, импортируйте выгрузку и откройте дашборд.
2. [Разберитесь в каркасе](starter.md#как-устроен-каркас) - найдите загрузку данных, фильтры и построение графиков.
3. [Выберите методы под свои вопросы](resources.md) - используйте пояснения и ссылки на документацию по мере исследования.
4. Записывайте результаты в [analysis.md](../solution/analysis.md).

## По темам

**Работа с репозиторием.** [Получение данных](../data/README.md), [первый запуск](starter.md#первый-запуск) и [помощь при ошибках](starter.md#если-что-то-не-работает).

**Исследование данных.** [Выбор визуализации](resources.md#визуализации), [статистические гипотезы](resources.md#статистические-гипотезы), [PCA и t-SNE](resources.md#pca-и-t-sne).

**Представление результатов.** [Карты](resources.md#карты) и [интерактивный дашборд](resources.md#интерактивный-дашборд).

Не нужно последовательно изучать все библиотеки из справочника. Начните с вопроса к данным и откройте документацию того инструмента, который помогает на него ответить.
