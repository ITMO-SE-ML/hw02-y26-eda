# Документация к ДЗ 2

Начните с [условия задания](../README.md), затем [скачайте данные](../data/README.md) и [запустите приложение](starter.md#первый-запуск).

В [инструкции к каркасу](starter.md#как-устроен-каркас) описано, где находятся загрузка данных, фильтры и графики. Если что-то не запускается, загляните в [раздел с частыми ошибками](starter.md#если-что-то-не-работает).

## Справка по темам

- [Визуализации](resources.md#визуализации) - выбор графиков и оформление.
- [Статистические гипотезы](resources.md#статистические-гипотезы) - тесты, эффекты и доверительные интервалы.
- [PCA и t-SNE](resources.md#pca-и-t-sne) - подготовка признаков и чтение проекций.
- [Карты](resources.md#карты) - точки, агрегация и координаты.
- [Дашборд](resources.md#интерактивный-дашборд) - фильтры и порядок графиков.

Результаты записывайте в [analysis.md](../solution/analysis.md) по ходу работы.
