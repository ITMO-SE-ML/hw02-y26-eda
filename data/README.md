# Данные вашего региона

[Условие задания](../README.md)

Источник - [«Карта ДТП»: открытые данные](https://dtp-stat.ru/opendata/). Здесь можно скачать регион и прочитать описание полей. Проект использует данные ГИБДД и исправляет часть ошибок, в том числе в координатах. Посмотрите, какой период охватывает ваша выгрузка.

## Получение

1. Из корня репозитория запустите `python data/assign_region.py YOUR_GITHUB_USERNAME`. Для одного username всегда получается один и тот же регион. Используйте свой логин и запишите регион в отчёт.
2. Откройте страницу источника и скачайте свой регион. По ссылке «Скачать .geojson» может скачаться ZIP-архив. Распаковывать его перед импортом не нужно.
3. Импортируйте скачанный файл:

```bash
.venv/bin/python data/import_data.py /path/to/region.geojson.zip
```

Можно передать и распакованный `.geojson`/`.json`. Скрипт проверит формат и скопирует данные в `data/raw`. Рядом появится `.source.json` с числом записей, датой импорта и SHA-256. Если такой файл уже есть, скрипт сверит содержимое: одинаковый файл пропустит, а при различиях попросит переименовать новую выгрузку. В этом случае распакуйте ZIP и переименуйте сам JSON/GeoJSON внутри.

4. Запустите `make run`. При нескольких файлах приложение предложит выбрать выгрузку.

Названия на сайте могут немного отличаться: "Кемеровская область" соответствует "Кемеровская область - Кузбасс", "Республика Татарстан" - "Республика Татарстан (Татарстан)". Если своего региона нет, напишите преподавателю практики. Пожалуйста, не подбирайте другой username ради смены региона.

Если копируете файл в `data/raw` вручную, запишите источник, дату и контрольную сумму сами. Выгрузку и `.source.json` в Git не добавляйте. Источник и версию данных укажите в `solution/analysis.md`.

## Структура

Обычно это GeoJSON FeatureCollection: `features` содержит происшествия, `properties` - свойства записи, `geometry.coordinates` - координаты. Среди полей встречаются время, территория, тип ДТП, тяжесть, освещённость и численность участников/пострадавших.

Вложенные списки:

- `vehicles` - транспортные средства; внутри них `participants` - участники;
- верхнеуровневый `participants` - участники вне транспортных средств;
- `weather`, `road_conditions`, `nearby`, `tags` - несколько значений одного поля.

Откройте несколько записей своей выгрузки: набор полей и их заполненность могут различаться, например возраст есть не всегда. После обычного вызова `pd.json_normalize` вложенные списки останутся в ячейках. Если они нужны для анализа, разверните их в отдельные таблицы и сохраните связь с исходным ДТП.
