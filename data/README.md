# Данные вашего региона

[Условие задания](../README.md)

Источник - [«Карта ДТП»: открытые данные](https://dtp-stat.ru/opendata/). На странице доступны выгрузки регионов и описание структуры. Первоисточник - данные ГИБДД; проект вносит корректировки, в том числе в координаты. Проверьте период и описание вашей конкретной выгрузки.

## Получение

1. Из корня репозитория запустите `python data/assign_region.py YOUR_GITHUB_USERNAME`. Назначение детерминированное: используйте свой настоящий username. Зафиксируйте результат в заметках.
2. Откройте страницу источника и скачайте свой регион. Ссылка «Скачать .geojson» может отдавать ZIP-архив — это нормально.
3. Импортируйте скачанный файл:

```bash
.venv/bin/python data/import_data.py /path/to/region.geojson.zip
```

Можно передать и распакованный `.geojson`/`.json`. Скрипт проверяет формат, сохраняет неизменённые записи в `data/raw` и рядом создаёт паспорт `.source.json` с числом записей, датой импорта и SHA-256. Повторный импорт идентичного файла безопасен; другую выгрузку с тем же именем он не перезаписывает. Чтобы сравнить версии, распакуйте новую выгрузку и переименуйте сам JSON/GeoJSON перед импортом; переименование ZIP не меняет имя файла внутри.

4. Запустите `make run`. При нескольких файлах приложение предложит выбрать выгрузку.

В названиях источника возможны уточнения: "Кемеровская область" соответствует "Кемеровская область - Кузбасс", "Республика Татарстан" - "Республика Татарстан (Татарстан)". Если назначенный регион недоступен, сообщите преподавателю практики; не меняйте username ради другого назначения (пожалуйста).

Можно положить файл непосредственно в `data/raw` без импортёра, но тогда самостоятельно зафиксируйте происхождение, дату и контрольную сумму. Данные и их локальный паспорт не коммитятся. Сведения о версии и источник перенесите в `solution/analysis.md`, чтобы другой человек мог воспроизвести загрузку.

## Структура

Обычно это GeoJSON FeatureCollection: `features` содержит происшествия, `properties` - свойства записи, `geometry.coordinates` - координаты. Среди полей встречаются время, территория, тип ДТП, тяжесть, освещённость и численность участников/пострадавших.

Вложенные списки:

- `vehicles` - транспортные средства; внутри них `participants` - участники;
- верхнеуровневый `participants` - участники вне транспортных средств;
- `weather`, `road_conditions`, `nearby`, `tags` - несколько значений одного поля.

Проверяйте фактическую схему: список полей и заполненность могут различаться. Возраст не гарантирован. `pd.json_normalize` без специального разворачивания сохраняет списки как значения ячеек; он не превращает их автоматически в отдельные таблицы. Выбор таблиц и связей - ваше аналитическое решение.
